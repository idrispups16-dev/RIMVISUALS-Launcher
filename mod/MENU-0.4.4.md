# RIMVISUALS menu 0.4.4-menu.1

The menu follows the supplied dark/violet reference: collapsible navigation, charcoal cards with inline controls, adaptive masonry grid and full module details. RIMVISUALS branding is retained. The complete 81-module registry and browser authorization are unchanged.

- Right Shift opens the menu.
- Click the top-left chevron or logo to collapse/expand the sidebar.
- The numbered header button cycles 1/2/3 columns. Narrow windows automatically use fewer columns to fit controls.
- Cards expose the first three visible non-text settings. Click a module title or its bottom-right ... to open all settings, colors and reset controls.
- The top-right field filters the current category by module/setting text.
- Click the bottom-left Account item for login/session controls.
- Sidebar sections retain HUD editing, utilities, CFG profiles, keybinds, friends and markers. Detailed controls and profile operations retain their existing behavior.
- Sidebar and column preferences are saved with the existing configuration.

Validation: MenuGrid geometry tests cover responsive widths and variable-height packing. Existing catalog, configuration, session and effect tests remain enabled. The Minecraft development startup test captures the actual menu, settings and auxiliary screens; it does not establish in-world appearance or performance.
