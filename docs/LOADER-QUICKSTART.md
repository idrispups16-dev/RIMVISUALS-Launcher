# RIMVISUALS Loader — быстрый старт (Windows)

1. Установите `RIMVISUALS-Setup.exe` (или запустите `RIMVISUALS.exe`). JAR мода уже внутри, искать его не нужно.
2. Запустите Minecraft **1.21.11 с Fabric Loader 0.19.3** через Legacy Launcher (профиль Fabric). Дождитесь главного меню.
3. Откройте RIMVISUALS → страница **Loader**. Через пару секунд игра появится в состоянии:
   - «RIMVISUALS не установлен» → нажмите **Установить мод**, подтвердите, затем **полностью закройте и снова запустите Minecraft** (Fabric загружает моды только при старте);
   - «Готово к подключению» → мод уже загружен, перезапуск не нужен.
4. Нажмите **CONNECT**. Статус «Подключено» появится только после ответа мода. Ниже откроется каталог модулей из игры.
5. В игре: **Right Shift** — ClickGUI.

Если что-то не работает: кнопка **Диагностика IPC** покажет, какой шаг не прошёл и что сделать. Логи: страница «Логи», файл `logs/latest.log` игры.
Горячего подключения к уже запущенной игре без перезапуска нет — это ограничение Fabric (см. LOADER-FEASIBILITY.md).
