В игре открыт экран HolyWorld API со статусом `response received; server policy applied`. Сделан штатный F2-скриншот. Записано игровое окно через Windows Game Bar; сокращённая запись длится 37 секунд и показывает статус API, мир HolyWorld и меню. Аудио удалено. Поддельные серверные ответы для этой записи не применялись.

Ограничения: запись начата после фактического получения ответа; сам момент handshake подтверждается строками журнала, а не видео сетевых пакетов. Точный ID единственной блокировки в текущем журнале не сохраняется, поэтому отдельное in-game подтверждение скрытия конкретной запрещённой функции этим видео не устанавливается. Fullbright был доступен в поиске, и его нельзя представлять как заблокированную функцию. Обработка blocklist и сохранение ограничений после загрузки профиля покрыты локальными тестами; для точечной live-демонстрации администрация может назначить известный ID в персональный blocklist клиента rimvisuals.

Ответ API — техническое подтверждение обмена и применения политики, а не официальное одобрение модификации. Telegram-канал проекта и приблизительное число пользователей ещё нужны от владельца.
